# cometchat_chat_uikit example

A minimal example app that initializes the CometChat Flutter UI Kit and renders
the `CometChatConversations` component.

## Run

1. Create an app in the [CometChat Dashboard](https://app.cometchat.com/) and
   copy its **App ID**, **Region**, and **Auth Key**.
2. Open [`lib/main.dart`](lib/main.dart) and replace the `_appId`, `_region`,
   `_authKey`, and `_uid` placeholder constants with your values.
3. Run the app:

   ```sh
   flutter run
   ```
